# BoxingCanvas-V0.1
App web full-stack che integra computer vision e arte generativa. Backend Python/FastAPI con REST API e frontend HTML/CSS/JS. MediaPipe e OpenCV rilevano i movimenti della mano, trasformati in immagini artistiche. Autenticazione Google OAuth 2.0/OIDC e database SQLite. 𝑰𝒏 𝒔𝒗𝒊𝒍𝒖𝒑𝒑𝒐 : ESP32 con sensore IMU per rilevare pugni via WiFi.
