# BoxingCanvas

Boxing Canvas is an interactive web application that combines **Computer Vision and Generative Art**, transforming hand movements into unique digital artworks.

*Technologies* : 

- *Python & FastAPI* – Backend and REST API.
- *HTML, CSS & JavaScript* – Frontend.
- *MediaPipe* – Real-time hand tracking.
- *OpenCV* – Camera and video processing.
- *SQLite* – User data storage.
- *Google OAuth 2.0 / OpenID Connect* – Authentication.

An IoT integration is currently under development using an *ESP32 and an IMU sensor* to independently detect punches and transmit movement data via Wi-Fi.

*Project Vision* :
Boxing Canvas explores the intersection of technology, movement and creativity, turning physical interactions into generative visual experiences.

---

*Project developed as an exploration of Computer Vision, Web Development and Generative Art.*
